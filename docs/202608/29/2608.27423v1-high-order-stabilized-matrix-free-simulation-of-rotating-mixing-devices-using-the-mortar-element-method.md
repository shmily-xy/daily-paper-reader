## 摘要
我们提出了一种使用Mortar单元法作为区域分解策略来模拟旋转混合设备的有限元框架。该模型在无矩阵Navier-Stokes框架内实现，采用高阶连续Galerkin方法。离散域被细分为转子和定子两部分。任意拉格朗日-欧拉方法处理转子-定子相对运动，并通过流线迎风/Petrov-Galerkin和压力稳定Petrov-Galerkin方法确保稳定性。转子-定子区域通过由mortar单元组成的界面连接，并以不连续Galerkin方式通过考虑转子-定子界面处的边界积分来弱强制连续性。二维稳态和瞬态例子中的收敛阶验证报告了最优速率。转子旋转在mortar界面处产生的几何非一致性不会在解中引入显著误差。使用三维例子研究模型的可扩展性，对于大规模问题获得了理想的强扩展性。二维Rushton叶轮例子使用扭矩分析展示了网格收敛性，相应的速度分布与现有数值结果一致。在三维斜叶涡轮案例中，功率数曲线（Np与Re的关系）在雷诺数1至2000范围内与实验数据吻合良好。能量平衡分析报告了Re=200时1%和Re=2000时10%的数值耗散。通过利用现代硬件能力并通过无矩阵方法，所提出的模型是适合模拟旋转几何体流动的稳健、准确且高效的框架。

## Abstract
We present a finite element framework to simulate rotating mixing devices using the Mortar Element Method as a domain decomposition strategy. The model is implemented within a matrix-free Navier-Stokes framework which uses a high-order Continuous Galerkin method. The discretized domain is subdivided into rotor and stator parts. An Arbitrary Lagrangian-Eulerian approach accounts for the relative rotor-stator motion, and stabilization is ensured through the Streamline-Upwind/Petrov-Galerkin and Pressure-Stabilizing Petrov-Galerkin methods. The rotor-stator domains are connected by an interface composed of mortar cells, and continuity is weakly enforced in a Discontinuous Galerkin fashion by accounting for boundary integrals at the rotor-stator interface. Verifications of the convergence order in two-dimensional steady and transient examples report optimal rates. The geometric non-conformity created at the mortar interface due to rotor rotation does not introduce significant error in the solution. A three-dimensional example is used to investigate the model's scalability, which yields ideal strong scaling for large problems. A two-dimensional Rushton impeller example uses a torque analysis to showcase the mesh convergence, and the corresponding velocity profile is in agreement with existing numerical results. In a three-dimensional pitched blade turbine case, the power number curve (Np vs Re) shows good agreement with experimental data for Reynolds number values from 1 to 2000. An energy balance analysis reports a numerical dissipation of 1% for Re=200 and of 10% for Re=2000. By exploiting modern hardware capabilities through matrix-free methods, the proposed model is a robust, accurate, and efficient framework suitable for simulating flows with rotating geometries.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：旋转混合设备（如搅拌罐、混合器）在化工、制药、食品等领域具有广泛应用，其内部流动对混合效率至关重要。由于转子与定子的相对运动以及复杂几何结构，这些设备的数值模拟极具挑战性：网格会随转子旋转而产生大变形，传统方法需要频繁重划分网格，导致精度损失和计算开销。
- **核心问题**：如何在不重复网格生成的前提下，准确、高效地模拟转子-定子之间的非一致界面流动？主流的滑移网格技术虽然可行，但存在限制；浸没边界法可能降低精度或恶化线性系统条件数。需要一种既保持高阶精度又具有良好可扩展性的方法。
- **论文目标**：提出并验证一个结合 **Mortar Element Method (MEM)** 与 **无矩阵(matrix-free)高阶有限元** 的框架，用于模拟旋转混合设备。MEM通过域分解弱强制转子-定子界面连续性，避免了网格重划分；无矩阵算法利用现代硬件能力，缓解了高阶方法的内存带宽瓶颈。
- **整体含义**：该工作填补了将MEM与无矩阵高阶求解器相结合的空白，为旋转几何流场模拟提供了一种稳健、精确且高效的数值方案，有助于理解、监测和优化流体驱动过程（如质量传递、热传递）。

## 2. 方法论（核心思想与关键技术细节）

- **数学模型**：采用任意拉格朗日-欧拉（ALE）形式的不可压缩Navier-Stokes方程，通过网格速度项计及转子运动。
- **Mortar元素法域分解**：
  - 计算域被划分为两个非重叠子域：转子（Ω⁻）和定子（Ω⁺）。
  - 在转子-定子界面处创建mortar单元，基于两侧网格边界的几何交点生成。
  - 界面连续性通过弱形式施加，采用不连续Galerkin（DG）方式，包括**对称内罚Galerkin (SIPG)** 方法处理粘性项、压强项使用中心数值通量，并引入罚参数。
- **稳定化方法**：采用SUPG（流线迎风/Petrov-Galerkin）和PSPG（压力稳定Petrov-Galerkin）稳定化，以处理对流主导和高雷诺数流动。
- **空间离散**：使用高阶连续Galerkin（CG）有限元，速度与压力场采用等阶 QP 元素（P≥2）。非线性系统用牛顿法求解。
- **无矩阵实现**：
  - 不组装全局矩阵，而是按单元在线计算残差和雅可比积，利用批量向量化和数据缓存优化性能。
  - 预条件器采用**全局粗化几何多重网格 (GCMG)**，其平滑器和粗网格求解器均与无矩阵架构兼容。
  - 算法流程：针对mortar界面单元，逐列重构对角项或矩阵项，避免整体矩阵存储。
- **网格更新与并行**：
  - 转子网格旋转通过旋转矩阵映射初始网格坐标得到。
  - 使用p4est库进行并行网格管理，采用空间填充曲线分解，并对转子-定子界面单元进行负载均衡（可调整权重）。
- **软件实现**：基于开源软件Lethe（基于deal.II库）实现，包含Mortar Manager、Coupling Operator和Coupling Evaluation三个核心组件。

## 6. 主要结论与发现

- **收敛性**：二维稳态MMS和瞬态TGV均获得最优收敛阶（速度O(h^(P+1))，压力O(h^P)），与非mortar参考结果一致。几何非一致（由转子旋转引起的mortar界面错位）不引入显著额外误差。

- **工程应用**：
  - 2D Rushton混合器的速度剖面与有限体积结果吻合，扭矩随网格细化收敛，且总扭矩和趋近于零（符合层流预期）。
  - 3D PBT混合器的功率数曲线在Re=1~2000范围内与实验数据良好吻合，且与NIB方法精度相当或略优。
- **能量耗散**：能量平衡分析显示，收敛网格在Re=200时数值耗散约为1%，Re=2000时约10%（Q2Q2 l=1），表明该方法能较准确地模拟过渡态/早期湍流流动。
- **负载均衡**：对mortar界面单元赋予更高权重（wm/wr=20）可显著降低负载不平衡，但对总计算时间影响不大，因此并非必需步骤。

## 7. 优点（方法与实验设计亮点）

- **方法创新性**：首次将Mortar单元法与无矩阵高阶有限元框架结合，充分发挥两者的优势。
- **精度高**：高阶（P≥2）元素在较粗网格上即可获得高精度，有效降低计算需求。
- **稳健性**：通过弱形式施加界面连续性，避免了强点连续对网格匹配的依赖，对非一致界面具有鲁棒性。
- **计算效率**：无矩阵算法减少内存带宽压力，配合GCMG预条件器，适合现代HPC架构。
- **验证全面**：既采用标准制造解验证收敛阶，又以实际搅拌设备验证工程可用性；同时提供能量平衡分析，量化数值耗散。
- **开源可复现**：实现基于Lethe/deal.II等开源软件，便于社区使用与扩展。

## 8. 不足与局限

- **界面网格限制**：当前模型要求转子-定子界面两侧单元数量相等且均匀分布（二维等角长度，三维平面内和轴向等尺寸），这限制了复杂几何的网格生成灵活性，也是一个与NIB方法相比的劣势。
- **线性有限元稳定性问题**：Q1Q1（线性速度-压力）元素在mortar界面上出现压力不稳定，需要bubble型富集函数；该方法仅在基于矩阵的求解器中验证，尚未集成到无矩阵框架中。因此论文中所有算例均使用P≥2。
- **负载均衡影响有限**：尽管研究了mortar单元权重对负载不平衡的影响，但发现其对总时间影响不大，说明当前并行策略仍有优化空间。
- **实验验证范围**：虽然验证了PBT混合器，但仅覆盖Re=1~2000，未测试更高雷诺数下的湍流充分发展状态；二维案例为基础几何，未涉及更复杂的工业混合设备。
- **计算资源说明**：论文报告了CPU集群上的扩展性，但未与GPU或更先进加速硬件进行对比。
- **未来工作**：需支持非结构化/变尺寸界面网格、变化界面半径，以及扩展至多物理场（如颗粒输运）耦合。
